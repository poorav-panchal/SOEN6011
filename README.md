# SOEN 6011 - Transcendental Function F6: Beta Calculator

## Description
This project implements the Beta Function $B(x,y)$ from first principles. As per the Deliverable 2 (D2) constraints, all core mathematical calculations (Gamma function, logarithms, exponentials, square roots, and sine) are implemented entirely from scratch without the use of built-in Python math libraries. 

## Requirements
* Python 3.x
* Tkinter (Usually bundled with standard Python installations)

## Execution
Run the application from your terminal:
```bash
python beta_calculator.py
